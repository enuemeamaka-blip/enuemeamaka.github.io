# Amaka Enueme — personal portfolio

A responsive, buildless HTML/CSS/JavaScript portfolio for GitHub Pages. All fonts and graphics are local or system-native; no packages or external services are required.

## Preview

Open `index.html` directly, or run `python -m http.server 8000` from this folder and visit `http://localhost:8000`.

## GitHub Pages

Push these files to the `enuemeamaka.github.io` repository. In **Settings → Pages**, select **Deploy from a branch**, choose the branch containing these files, and select **/(root)**. The website will be served at `https://enuemeamaka-blip.github.io/enuemeamaka.github.io/` when GitHub finishes deployment.

## Editing

- `index.html`: content, section order, links, metadata.
- `assets/css/styles.css`: colors, typography, responsive layouts, lab equipment animation.
- `assets/js/main.js`: mobile navigation, current section indicator, motion toggle.
- `assets/images/`: favicon and future photography or figures. Current illustrations are SVG/CSS, so no stock imagery is required.
- `assets/documents/amaka-enueme-cv.pdf`: supplied academic CV, available to view and download.

Content is drawn from the supplied CV. Roles marked “Present” retain the CV's status and are explicitly labeled. No current employment has been independently verified. The manuscript in preparation is separate from published work. Add a portrait, verified LinkedIn/ORCID links, project figures, or more detailed project pages when available; none are fabricated here.

The contact link opens the visitor's email application. There is no contact form or backend. Decorative motion has a pause/play control and respects the system reduced-motion preference. The site remains readable and navigable without JavaScript.

The CV is publicly downloadable when this repository is published and includes the contact details in the original document.

## Portfolio photography

Selected supplied photographs appear in About, Projects, Experience, Awards, and Volunteering. Browser-ready WebP copies are in `assets/images/optimized/`; originals are preserved. HEIC-encoded award photography was converted to WebP. Photographs include alt text, lazy loading, and responsive layouts. The research summary opens at full size when selected.
